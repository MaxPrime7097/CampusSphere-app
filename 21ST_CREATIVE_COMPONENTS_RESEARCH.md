## 🎨 ADAPTATION GUIDELINES

When installing selected components:

### 1. **Color Tokens**
Replace component colors with CampusSphere palette:
```tsx
// Replace generic colors
bg-blue-500 → bg-primary (hsl(33 100% 51%))
text-gray-900 → text-foreground
border-gray-300 → border-border
```

### 2. **Typography**
Apply brand fonts:
```tsx
// Headings
className="font-raleway font-bold"

// UI elements
className="font-poppins font-medium"

// Body text
className="font-nunito"
```

### 3. **Motion**
Import @cs/brand motion tokens:
```tsx
import { fadeInUp, stagger } from '@cs/brand/tokens/motion';
```

### 4. **Spacing & Scale**
Use consistent spacing (4px grid):
```tsx
gap-4, gap-6, gap-8 (not arbitrary values)
```
