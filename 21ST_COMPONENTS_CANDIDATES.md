## 🎨 Adaptation Guidelines

### Pour chaque composant importé:

✅ **À faire:**
1. Remplacer les couleurs hardcodées par tokens @cs/brand
2. Adapter typographie (Raleway, Poppins, Nunito)
3. Importer motion variants depuis @cs/brand
4. Vérifier responsive behavior
5. Tester dark mode

❌ **À éviter:**
- Ne pas garder les gradients néon
- Pas de glow excessif
- Pas d'aurora backgrounds
- Pas de glassmorphism systématique
- Max 1 effet animé par section

### Color Mapping:
```typescript
// Remplacer dans les composants importés:
primary → hsl(33 100% 51%)     // Orange CampusSphere
success → hsl(142 71% 42%)     // Green
info    → hsl(210 90% 50%)     // Blue
purple  → hsl(280 70% 55%)     // Purple
```

### Typography Mapping:
```typescript
// Remplacer dans les composants importés:
h1, h2 → font-raleway
buttons, labels → font-poppins
body, p → font-nunito
```
